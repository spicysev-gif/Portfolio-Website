Project

MUREX Underwater Robotics ROV

An open-source underwater ROV designed for the 2024 MATE ROV competition. Built around a modular 6-DOF chassis, 7-DOF arm, and a custom electrical stack that undercuts commercial costs.

Overview

I led the design of a fully open-source underwater ROV intended to be small, low-cost, and modular without sacrificing capability. We focused on doing it right: open tooling, validated subsystems, and repeatable performance under competition conditions.

Highlights

  • 6-DOF frame with 7-DOF manipulator arm and modular mounts.
  • Custom PCBs for control, power, and sensor fusion.
  • Multi-camera vision with IP + USB streams.
  • Open-source stack that undercuts commercial costs by 88%.
  • Broke 10 industry records and placed 5th at Worlds.

Systems approach

Mechanical, electrical, and software teams worked in parallel. I standardized interfaces and enclosure dimensions so each subsystem could be developed asynchronously and still assemble cleanly.

  • Standardized connectors across boards and harnesses.
  • Mechanical frame designed for rapid swaps and upgrades.
  • Control stack tuned for stable 6-DoF motion.

Carrier Board

Raspberry Pi CM4-based control board with USB 3.0 support, 10-DoF IMU, and integrated sensor fusion. Provides main computing platform for ArduPilot and vision processing.

Power Board

High-efficiency DC-DC conversion with real-time current monitoring, overcurrent protection, and voltage regulation. Supports multiple power rails for electronics and thrusters.

ANYESC + ESC Carrier

Modular electronic speed controller system for thruster control. Enables independent control of 6+ thrusters with CAN bus communication and real-time telemetry.

Photo idea: ethernet switch with magnetics.

Ethernet Switch

Compact 5-port 100BASE-TX managed switch with PoE support. Aggregates camera streams and control data with low-latency switching for real-time operation.

Vision System

Multi-camera system with IP and USB 3.0 cameras providing forward, downward, and manipulator views. Low-latency streaming with hardware encoding for real-time pilot feedback.

Manipulators

7-DOF manipulator arm with precision control for mission tasks. Features modular joints, waterproof servo casings, and integrated force feedback for delicate operations.

8 DOF Frame

Modular frame system providing 8 degrees of freedom for precise underwater maneuvering and positioning. Designed for optimal thruster placement and stability across all axes of motion.

Vertical Profiling Float

Automated vertical profiling system for oceanographic data collection. Enables controlled ascent and descent for water column sampling, temperature profiling, and depth-based measurements with precise depth control.

Waterproof Servo Casing

World's cheapest fully waterproof servo casing rated to 5 meters depth. Saves 97% cost compared to commercial cases. Oil-free design tested in all orientations for reliable operation regardless of servo mounting direction.
